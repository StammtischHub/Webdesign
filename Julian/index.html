Kernkonzepte

Drei Bausteine bestimmen den technischen Aufbau des Spiels.

01 // Herzstück

Game Loop

Der Game Loop hält das Spiel kontinuierlich am Laufen. Über requestAnimationFrame() wird für jedes neue Browser-Frame ein weiterer Durchlauf gestartet.

Dabei werden Eingaben verarbeitet, Positionen und Geschwindigkeiten aktualisiert, Kollisionen geprüft und anschließend die aktuelle Szene auf das Canvas gezeichnet.

Delta Time beschreibt die vergangene Zeit seit dem letzten Frame. Bewegungen werden damit zeit- statt frameabhängig berechnet und bleiben auch bei unterschiedlichen Bildraten möglichst konstant.

02 // Physik

Formeln

Position und Fallgeschwindigkeit werden in jedem Frame mithilfe von Delta Time aktualisiert.

03 // Canvas

Rendering

Die gesamte Spielszene wird auf den Canvas direkt im Browser gezeichnet. Anders als bei klassischen HTML-Elementen existieren Spieler, Barrieren und Spielfeld dabei nicht als einzelne DOM-Elemente.

Stattdessen zeichnet jeder Frame den aktuellen Spielzustand neu auf das Canvas. Positionen und Größen stammen aus zuvor berechneten Spieldaten und werden über den 2D-Kontext dargestellt.

Die Zeichenreihenfolge bestimmt, welche Elemente vor oder hinter anderen erscheinen. Das Canvas wird daher in jedem Frame geleert und anschließend Schicht für Schicht neu aufgebaut.

Audio Design.

Sounds

Alle Soundeffekte wurden selbst aufgenommen und anschließend zugeschnitten und bearbeitet. Sie liegen als Mono-Dateien in FLAC, Opus und OGG vor.

01 // SPRUNG

Jump

Ein kurzer Luftstoß mit den Lippen erzeugt ein weiches „Plopp“. Der Sound wird bei jedem Sprung des Vogels abgespielt und gibt direktes akustisches Feedback.

02 // KOLLISION

Slap

Ein Schlag mit der flachen Hand auf den nackten Oberschenkel erzeugt den kräftigen Aufprall. Er erklingt, sobald der Vogel mit einer Barriere kollidiert.

03 // VOID

Scream

Ein aufgenommener Schrei begleitet den Absturz des Vogels. Durch ein Fade-out wird der Sound zunehmend leiser und vermittelt akustisch das Fallen in die Tiefe.

04 // HIGHSCORE

Highscore

Das helle Klingeln eines Lindt-Goldhasen dient als positives Feedback. Der Sound wird abgespielt, sobald ein neuer Highscore erreicht wurde.

03 // Audacity

Honorable Mention

Die aufgenommenen Rohdateien wurden in Audacity zugeschnitten und nachbearbeitet. Dabei wurden unter anderem Hintergrundrauschen entfernt, Lautstärken angepasst und gegebenenfalls ein Fade-out erzeugt.

Wichtig war, die Sounds kurz und klar unterscheidbar zu halten. Anschließend wurden sie als Mono-Audio in FLAC, Opus und Ogg Vorbis exportiert.
